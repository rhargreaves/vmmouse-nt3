VMMouse for Windows NT 3.x
==========================
Version:    @VERSION@
Author:     Robert Hargreaves
Repository: https://github.com/rhargreaves/vmmouse-nt3

About
-----
QEMU / VMware mouse integration driver for Windows NT 3.x.

Requirements
------------
- Windows NT 3.1 (Intel) or greater
  Note: Only tested in Windows NT 3.51 SP5. But it *should* work in earlier releases too!
- QEMU or VMware

Installation
------------
1. Open Command Prompt (or File Manager)
2. Run D:\INSTALL.BAT
   (Replace D: with your CD-ROM drive letter).
3. Reboot

Uninstallation
--------------
1. Open a Command Prompt
2. Run D:\UNINSTALL.BAT
3. Reboot
